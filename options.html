Interpretab options

Gemini API key

Interpretab has no server. Your audio goes straight from this browser to the Gemini Live API, authenticated with your own key — get a free one at aistudio.google.com/apikey. The key is stored in this browser's extension storage and is sent nowhere except generativelanguage.googleapis.com. Usage is billed to the Google account the key belongs to, so treat it like a password: don't share it, and don't paste it anywhere else. If it ever gets out, delete it on the same page you made it on and paste a new one in here.

Gemini API plan

Which plan the key's project is on. Interpretab has no way to tell — no Gemini API response says — and it has to know, because the side panel's meter would otherwise show a price to people Google charges nothing. On Free the meter counts time and audio; on Paid it also estimates what the run has cost. Pick the one your key is on: it is the project you made it in at aistudio.google.com/apikey, and a project is on the paid tier once it has a billing account linked.

Voice

The prebuilt voice the translation is spoken in. Fixed for the life of a session, so a change applies the next time you press Start.

Subtitle size

How tall the on-page subtitles are, in pixels. Applies immediately, even to a translation already running — drag it while watching the video and stop where it reads well.

The quick brown fox — 素早い茶色の狐

Microphone

Chrome grants the microphone to the extension as a whole. The engine runs in a background document that cannot show a permission prompt, so if the microphone direction fails, grant it once from here.

Audio input

Which microphone the microphone direction listens to. Left on the system default, Chrome picks whatever your computer currently calls the input — which may be a headset you have unplugged, a monitor, or some other device you never speak into. That failure is silent: the session connects, the panel goes green, and nothing is ever transcribed. Name the device here if that happens. Applies the next time you press Start.

Audio output

Where the microphone direction's translated voice is played. The tab direction's translation always stays on the system output — that is the one you are listening to. Applies the next time you press Start.

Glossary

source,pronunciation,transcript per line. The second column is what the model is told to say; the optional third is what the captions show instead. Applies to the microphone in Two-way conversation mode only: everything else — tab audio, and the microphone's Simultaneous mode — runs the simultaneous-translation model, which takes no system instruction and so has nowhere to put a glossary.
