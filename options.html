Interpretab options

Gemini API key

Interpretab has no server. Your audio goes straight from this browser to the Gemini Live API, authenticated with your own key — get a free one at aistudio.google.com/apikey. The key is stored in this browser's extension storage and is sent nowhere except generativelanguage.googleapis.com. Usage is billed to whichever Google Cloud project the key belongs to, so treat it like a password and restrict it to the Generative Language API.

Voice

The prebuilt voice the translation is spoken in. Fixed for the life of a session, so a change applies the next time you press Start.

Subtitle size

How tall the on-page subtitles are, in pixels. Applies immediately, even to a translation already running — drag it while watching the video and stop where it reads well.

The quick brown fox — 素早い茶色の狐

Microphone

Chrome grants the microphone to the extension as a whole. The engine runs in a background document that cannot show a permission prompt, so if the microphone direction fails, grant it once from here.

Glossary

source,pronunciation,transcript per line. The second column is what the model is told to say; the optional third is what the captions show instead. Applies to the microphone direction only: tab audio always runs the simultaneous-translation model, which takes no glossary.
