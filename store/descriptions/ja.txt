Interpretab は、ブラウザが再生している音声 — 動画、ウェビナー、カンファレンスの配信、Meet の相手側 — を、あなたの言語に、声とページ上の字幕で、その場で翻訳します。

プレーヤーに後付けした字幕ツールでもなければ、元の言葉を覆い隠す吹き替えツールでもありません。両方を出し、しかも双方向です。

▍ 声だけでなく、ページの上に字幕

翻訳は動画に重ねて読み上げられ、同時に動画の上に書き出されます。画面下部中央に 3 行がロールし、全画面表示にも追従します。聞き取れなかった用語は読んで確かめ、残りは耳で聞く。字幕のスイッチは方向ごとに独立しているので、自分の声は字幕にせず動画だけ字幕にする、といった使い分けができ、セッション中に切り替えても接続は切れません。

▍ 双方向を、同時に

タブの音声をあなたの言語へ。マイクの音声を相手の言語へ。英語で話せば、その場にいる人には日本語で伝わり、相手の日本語は英語で返ってきます。2 つは独立したセッションとして動くので、片方だけ止めることもできます。二者間会話モードでは、自分の訳が再生されているあいだマイクをミュートするので、通訳が自分自身を通訳してしまうことはありません。同時通訳モードは話し終わる前から訳しはじめます — それが「同時」の意味です — のでヘッドホンを使ってください。

▍ Meet、Zoom、Teams

両方向をオンにして、向きを逆に設定します。会議タブはあなたの言語へ字幕付きで、マイクは相手の言語へ。相手の声を聞くほうはすぐに使えます。こちらの声を相手に届けるには仮想オーディオデバイスが必要で（「できないこと」を参照）、Interpretab は翻訳した声をそこへ流し、相手側の翻訳はスピーカーに残します。

▍ 1 台のマイクを、2 人で

マイクにはもう 1 つのモードがあります。英語 ⇄ 日本語を設定してノート PC を 2 人のあいだに置けば、Interpretab は聞こえたほうの言語をもう一方へ通訳します。ボタンを押す必要も、向きを切り替える必要もありません。机の上、カウンター、ホテルのフロント、タクシーの中で。既定の同時通訳モードは、あなた 1 人の声を、文が終わるのを待たずに訳します。

▍ 用語を外さない用語集

製品名、人名、専門用語は、汎用モデルがいちばん崩すところであり、そこが崩れると翻訳全体が信用できなくなります。CSV をアップロードすれば、Interpretab は各用語の読み方を指示されます。字幕での表記は別の列で指定できるので、発音を固定しても、読み手に音写表記を押しつけずに済みます。

▍ 元の音は下がるだけで、消えない

Interpretab はタブ本来の音声をそのまま再生し、翻訳音声が話しているあいだだけ音量を下げて、終わればすぐ戻します。常時ではなく発話に反応する方式なので、映画の劇伴が無音のあいだずっと絞られたままになりません。下げ幅はスライダーで調整できます。

▍ サーバなし。あなたの鍵。あなたの音声。

Interpretab は、あなたが用意した API キーで Google の Gemini Live API に直接つなぎます。仲介するサービスはありません。そもそもサービスが存在しないからです。開発者は何も動かさず、何も見ず、何も保存しません。音声はブラウザから Google へ渡るだけで、拡張機能が到達できるホストはただ 1 つ — ほかの宛先は原理的にあり得ません。

無料のキーは aistudio.google.com/apikey で取得し、オプション画面に貼り付けてください。

▍ 言語

タブ音声: ソース言語は自動判定 — タブは流れてくるものを流すだけで、話者が途中で変わるたびに設定を変えさせるべきではありません。出力は 78 言語。

マイク: 同時通訳モードでもソース言語は自動判定され、同じ 78 言語から選べます。二者間会話モードでは、97 言語からペアの両方を指定します。声はどちらの場合も 30 種類から選択できます。

▍ 使い方

1. Gemini API キーをオプション画面に貼り付けます。
2. 翻訳したいページを開き、そのタブで Interpretab のツールバーアイコンをクリックします。このクリックがタブへのアクセス許可になります。
3. サイドパネルで言語を選び、Start を押します。

サイドパネルを閉じても翻訳は止まりません。

▍ できないこと

限界を先に、正直に:

• あなたの声の翻訳を Meet や Zoom のマイクに届けるには、仮想オーディオデバイス（BlackHole、VB-Cable）が必要です — 拡張機能が自分をマイクとして登録することはできません。オプション → 音声出力でそこへ流せますが、デバイスの導入と会議側での選択はご自身で行ってください。
• 両方向をスピーカーで鳴らすとエコーループになります。ヘッドホンを使ってください。声に出して話すことが前提の二者間会話モードでは、代わりにマイクをスピーカーから離してください。
• 用語集が効くのはマイクの二者間会話モードだけです。それ以外は Google の同時翻訳モデルを使っており、こちらは用語集を受け付けません。
• 双方向は Gemini のセッションを 2 つ同時に張るということなので、キーの API 使用量はおよそ 2 倍になります。
• Chrome は拡張機能が Chrome 自身のページ、ウェブストア、PDF に描画することを許していないため、そこでは字幕が出ません。音声とサイドパネルの履歴は動作します。

▍ 費用

Interpretab は無料でオープンソースです。Gemini API の利用料は Google の料金でご自身の Google アカウントに請求されます。無料枠だけでも一通り試せます。キーはパスワードと同じように扱ってください。共有せず、万一漏れたら aistudio.google.com/apikey で削除し、新しいものをオプション画面に貼り直してください。
