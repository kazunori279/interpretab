Interpretab は、ブラウザのタブが再生する音声や、マイクで話した声を、Gemini Live API でリアルタイムに翻訳します。訳した内容は声で読み上げ、同時にページ上に字幕として表示します。

• ネット動画や配信、ポッドキャスト、オンラインミーティングの音声を、78 言語で聞ける・読める
• プレゼンや配信のときに、自分の声を翻訳した字幕を、共有している画面にそのまま載せられる
• Google Meet では、自分の声を翻訳した吹き替え音声が相手に届く
• PC や Mac のマイクを使って、目の前の相手との会話をその場で通訳できる

ブラウザが Gemini API に直接つながり、あなた自身が用意した Gemini API キーで動きます。あいだに入るサーバはなく、無料プランのキーなら費用もかかりません。

ユーザーガイド: https://kazunori279.github.io/interpretab/

▍ 読み上げながら、画面にも字幕を出す

字幕は画面下部中央に 3 行で表示され、全画面表示でも使えます。大きさはオプション画面のスライダーで 16〜64 px まで変えられます。

▍ タブもマイクも同時に翻訳

ブラウザのタブの音声はあなたの言語に、マイクの音声は相手の言語に翻訳します。英語で話せば、その場にいる人には日本語で伝わり、相手の日本語は英語で返ってきます。マイク音声翻訳では、マイクに話すと同時に訳し始める Simultaneous（同時翻訳モード）と、2 つの言語間での会話を逐次翻訳する Two-way conversation（2 言語間翻訳モード）が利用できます。

▍ オンラインミーティングで使う

オンラインミーティングでは、相手の音声が翻訳されて再生され、字幕も表示されます（ただしブラウザのタブで使えるオンラインミーティングツールに限られます）。

Google Meet なら、Meet の音声設定で「Interpretab (translated)」を選ぶだけで、こちらの音声を翻訳して相手に送れます。それ以外のサービスでは仮想オーディオデバイスが必要です（「おもな注意点」を参照）。

▍ 元の音は下がるだけで、消えない

Interpretab はタブ本来の音声をそのまま再生し、翻訳音声が話しているあいだだけ音量を下げて、終わればすぐ戻します。常時ではなく発話時にのみ音量が下がります。下げ幅はスライダーで調整できます。

▍ 用語を外さない用語登録機能

Two-way conversation（2 言語間翻訳モード）では、製品名、人名、専門用語の読みと表記を登録できます。

▍ 中間のサーバなし。ブラウザが Gemini Live API と直接接続

Interpretab は、利用者が取得した API キーで Google の Gemini Live API に直接つなぎます。あいだに入る外部サーバや中間サービスはありません。音声や字幕のデータは Google 以外に届くことはないので、セキュリティも安心です。

▍ 対応する言語

タブ音声翻訳: ソース言語は自動で判定します。タブは流れてきた音をそのまま鳴らすだけですし、動画の途中で話者が変わるたびに設定を変えるのも面倒です。出力は 78 言語。

マイク音声翻訳: Simultaneous モードではソース言語は自動判定され、同じ 78 言語から選べます。Two-way conversation モードでは、97 言語からペアの両方を指定します。

▍ 使い方

1. Gemini API キーをオプション画面に貼り付け、そのキーが Google の Free と Paid のどちらのプランかを選びます。
2. 翻訳したいページを開き、そのタブで Interpretab のツールバーアイコンをクリックします。このクリックがタブへのアクセス許可になります。
3. サイドパネルで言語を選び、Start を押します。

詳しくはユーザーガイドをご覧ください: https://kazunori279.github.io/interpretab/

▍ おもな注意点

• これは機械翻訳です。聞き間違え、名前を推測し、話者が言っていないことを言うこともあります。翻訳の間違いによって大きな影響が出る用途には使わないでください。
• Google Meet 以外では、マイク翻訳の音声を会議アプリに送るための仮想オーディオデバイス（BlackHole、VB-Cable）が必要です。
• 用語登録機能が使えるのはマイク翻訳の Two-way conversation モードだけです。それ以外は Google の同時翻訳モデルを使っており、こちらは用語集を受け付けません。

▍ 費用

翻訳機能を提供する Gemini Live API にはお試しに使える無料プランと、継続利用に向いている有料プランがあります。有料プランの場合、2026 年 8 月時点の価格では、タブ音声翻訳で 1 時間あたり約 $2.20、Two-way conversation モードで 1 時間あたり約 $1.40 です。

無料プランと有料プランの違いについて、詳しくはユーザーガイドをご覧ください: https://kazunori279.github.io/interpretab/
