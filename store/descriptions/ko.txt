Interpretab은 브라우저가 재생 중인 소리 — 동영상, 웨비나, 콘퍼런스 스트림, Meet 통화의 상대편 — 를 내 언어로, 음성과 화면 위의 자막으로, 그 자리에서 옮겨 줍니다.

플레이어에 덧붙인 자막 도구도 아니고, 원래의 말을 덮어 버리는 더빙 도구도 아닙니다. 둘 다 주고, 게다가 양방향입니다.

▍ 음성만이 아니라, 페이지 위의 자막

번역은 영상 위로 소리 내어 읽히는 동시에 영상 위에 글로도 적힙니다. 화면 아래 가운데에 세 줄이 흘러가고, 전체 화면으로 들어가도 따라갑니다. 놓친 용어는 눈으로 확인하고 나머지는 귀로 들으세요. 자막 스위치는 방향마다 따로 있어서, 내 말은 자막 없이 영상만 자막을 켤 수 있고, 세션 도중에 바꿔도 연결이 끊기지 않습니다.

▍ 양쪽 방향을, 동시에

탭 소리는 내 언어로, 마이크는 상대의 언어로. 영어로 말하면 같은 자리에 있는 사람에게는 한국어로 전달되고, 그들의 한국어는 영어로 돌아옵니다. 두 방향은 독립된 세션으로 돌아가므로 한쪽만 끌 수도 있습니다. 양방향 대화 모드에서는 자기 번역이 재생되는 동안 마이크를 음소거하므로 통역기가 자기 자신을 통역하는 일이 없습니다. 동시통역 모드는 말이 끝나기 전에 답하기 때문에 — 그래서 '동시'입니다 — 헤드폰을 쓰세요.

▍ Meet, Zoom, Teams

양쪽 방향을 켜고 서로 반대로 맞추면 됩니다. 회의 탭은 자막과 함께 내 언어로, 마이크는 상대의 언어로. 상대의 말을 듣는 쪽은 어떤 서비스에서든 바로 됩니다.

Google Meet에서는 내 말을 들려주는 쪽도 설치할 것 없이 됩니다. 사이드 패널이 번역 음성을 실은 마이크를 통화에 내어 주므로, Meet의 오디오 설정에서 ‘Interpretab (translated)’를 고르기만 하면 됩니다. 당신 목소리도 아래에 작게 섞여 있어 통화에서는 통역과 당신 목소리가 함께 들립니다. 그 밖의 서비스에서는 가상 오디오 장치가 필요하며(‘할 수 없는 것’ 참고), Interpretab이 번역된 목소리를 그쪽으로 보내는 동안 상대편 번역은 스피커에 그대로 남습니다.

▍ 마이크 하나로, 두 사람이

마이크에는 두 번째 모드가 있습니다. 영어 ⇄ 한국어로 설정하고 노트북을 두 사람 사이에 놓으면, Interpretab이 들리는 쪽 언어를 다른 쪽으로 통역합니다. 누를 버튼도, 방향을 바꿀 일도 없습니다. 책상에서, 카운터에서, 호텔 프런트에서, 택시 안에서. 기본값인 동시통역 모드는 나 혼자만 통역하며 문장이 끝나기를 기다리지 않습니다.

▍ 용어를 틀리지 않는 용어집

제품명, 사람 이름, 전문 용어야말로 범용 모델이 가장 잘 망가뜨리는 부분이고, 그게 망가지면 번역 전체가 미덥지 않아집니다. CSV를 올리면 Interpretab에 각 용어를 어떻게 읽어야 하는지가 전달됩니다. 자막에 어떻게 적을지는 별도의 열로 지정하므로, 발음을 고정해도 읽는 사람에게 소리 나는 대로의 표기를 강요하지 않습니다.

▍ 원음은 낮아질 뿐, 사라지지 않습니다

Interpretab은 탭 본래의 소리를 그대로 들려주고, 번역 음성이 말하는 동안에만 볼륨을 낮췄다가 끝나면 곧바로 되돌립니다. 항상 눌러 두는 것이 아니라 발화에 반응하는 방식이라, 영화 음악이 조용한 구간 내내 눌려 있지 않습니다. 낮추는 정도는 슬라이더로 조절합니다.

▍ 서버 없음. 내 키. 내 오디오.

Interpretab은 사용자가 준비한 API 키로 Google의 Gemini Live API에 직접 연결합니다. 중개 서비스가 없습니다. 애초에 서비스라는 것이 존재하지 않기 때문입니다. 개발자는 아무것도 운영하지 않고, 아무것도 보지 않으며, 아무것도 저장하지 않습니다. 오디오는 브라우저에서 Google로만 가고, 확장 프로그램이 닿을 수 있는 호스트는 정확히 하나뿐입니다 — 다른 목적지는 아예 불가능합니다.

무료 키는 aistudio.google.com/apikey에서 받아 옵션 화면에 붙여 넣으세요.

▍ 언어

탭 오디오: 원본 언어는 자동 감지 — 탭은 나오는 대로 재생될 뿐이고, 화자가 중간에 바뀔 때마다 설정을 바꾸게 해서는 안 되니까요. 대상 언어는 78개.

마이크: 동시통역 모드에서도 원본 언어는 자동으로 감지되고 같은 78개 중에서 고릅니다. 양방향 대화 모드에서는 97개 중에서 한 쌍의 두 언어를 직접 지정합니다. 목소리는 어느 쪽이든 30가지 중에서 고를 수 있습니다.

▍ 사용법

1. Gemini API 키를 옵션 화면에 붙여 넣습니다.
2. 번역할 페이지를 열고, 바로 그 탭에서 Interpretab 툴바 아이콘을 클릭합니다. 이 클릭이 해당 탭에 대한 접근 권한이 됩니다.
3. 사이드 패널에서 언어를 고르고 Start를 누릅니다.

사이드 패널을 닫아도 번역은 멈추지 않습니다.

▍ 할 수 없는 것

한계를 먼저, 솔직하게:

• Google Meet 밖에서는 내 목소리의 번역이 회의 앱의 마이크에 닿으려면 가상 오디오 장치(BlackHole, VB-Cable)가 필요합니다 — 어떤 확장 프로그램도 스스로를 시스템 마이크로 등록할 수는 없습니다. 옵션 → 오디오 출력에서 그쪽으로 보낼 수 있지만, 장치를 설치하고 회의에서 선택하는 일은 사용자 몫입니다.
• 양쪽 방향을 스피커로 켜면 에코 루프가 생깁니다. 헤드폰을 쓰세요. 소리 내어 말하는 것이 목적인 양방향 대화 모드에서는 대신 마이크를 스피커에서 멀리 두세요.
• 용어집은 마이크의 양방향 대화 모드에서만 적용됩니다. 나머지는 모두 용어집을 받지 않는 Google의 동시 번역 모델을 씁니다.
• 두 방향은 Gemini 세션 두 개를 동시에 여는 것이므로, 키의 API 사용량이 대략 두 배가 됩니다.
• Chrome은 확장 프로그램이 Chrome 자체 페이지, 웹 스토어, PDF에 그리는 것을 허용하지 않으므로 그런 곳에서는 자막이 나오지 않습니다. 오디오와 사이드 패널 기록은 그대로 동작합니다.

▍ 비용

Interpretab은 무료이며 오픈 소스입니다. Gemini API 사용료는 Google의 요금으로 본인의 Google 계정에 청구됩니다. 무료 등급만으로도 제대로 시험해 볼 수 있습니다. 키는 비밀번호처럼 다루세요. 공유하지 말고, 혹시 유출되면 aistudio.google.com/apikey에서 삭제한 뒤 새 키를 옵션 화면에 붙여 넣으세요.
