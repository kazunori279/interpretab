Interpretab 把浏览器正在播放的声音——视频、网络研讨会、大会直播、Meet 通话里对方的发言——实时译成你的语言，既读出来，也写在页面上。

它不是硬塞进播放器的字幕工具，也不是把原话盖掉的配音工具。两样都给你，而且是双向的。

▍ 不只是声音，页面上还有字幕

译文一边被读出来，一边写在视频上：画面底部居中，三行滚动，进入全屏也跟着走。没听清的术语用眼睛确认，其余用耳朵听。两个方向各有独立的字幕开关，所以你可以只给视频加字幕而不给自己加，并且在会话进行中切换也不会断开连接。

▍ 两个方向，同时进行

标签页的声音译成你的语言，你的麦克风译成对方的语言。你说英语，身边的人听到的是中文；他们说中文，回到你耳朵里的是英语。两者作为独立会话运行，可以只关掉其中一个。在双向对话模式下，自己的译音播放时麦克风会静音，所以口译不会去翻译它自己；同声传译模式在你还没说完时就开始回应——这正是「同声」的含义——所以请戴耳机。

▍ Meet、Zoom 和 Teams

把两个方向都打开，并让它们朝相反的方向：会议标签页译成你的语言并配字幕，你的麦克风译成对方的语言。听懂对方这一侧立刻就能用。让对方听懂你则需要一个虚拟音频设备（见「它做不到什么」）；Interpretab 会把你的译音送进那个设备，而对方一侧的译音仍留在你的扬声器上。

▍ 一支麦克风，两个人

麦克风还有第二种模式。设成英语 ⇄ 中文，把笔记本放在两人之间，Interpretab 听到哪一边的语言就译成另一边——不用按按钮，也不用切换方向。办公桌前、柜台边、酒店前台、出租车里都可以。默认的同声传译模式只翻译你一个人，并且不等你把话说完。

▍ 让术语不跑偏的词汇表

产品名、人名和行话恰恰是通用模型最容易弄错的地方，而一旦弄错，整段翻译就显得不可信。上传一个 CSV，Interpretab 就知道每个术语该怎么念；字幕里该怎么写另有一列，所以固定了读音，也不会把音译写法强加给读者。

▍ 原声只是压低，不会消失

Interpretab 会把标签页本来的声音放给你听，只在译音说话时压低音量，说完立刻恢复。它由语音触发而非一直压着，所以电影配乐不会在每一段静默里都被摁住。压低多少由滑块决定。

▍ 没有服务器。你的密钥。你的音频。

Interpretab 用你提供的 API 密钥直接连接 Google 的 Gemini Live API。中间没有代理服务，因为根本就没有服务：开发者不运行任何东西，看不到任何东西，也不保存任何东西。你的音频从浏览器直达 Google，不去别处；这个扩展程序被允许访问的主机恰好只有一个——别的目的地根本不可能。

到 aistudio.google.com/apikey 免费获取密钥，粘贴到「选项」页面即可。

▍ 语言

标签页音频：源语言自动识别——标签页放什么就是什么，视频切到第二位讲者时不该还要你去改设置。目标语言 78 种。

麦克风：同声传译模式下同样自动识别源语言，目标语言同为那 78 种。双向对话模式下，你从 97 种语言里指定这一对的两端。两种情况都可以从 30 个语音中挑选。

▍ 怎么用

1. 把 Gemini API 密钥粘贴到「选项」页面。
2. 打开要翻译的页面，并在那个标签页上点击 Interpretab 工具栏图标。这一次点击就是你对该标签页的授权。
3. 在侧边栏选好语言，按 Start。

关掉侧边栏不会让翻译停下来。

▍ 它做不到什么

先把限制说清楚：

• 你的译音要进入 Meet 或 Zoom 的麦克风，只能经由虚拟音频设备（BlackHole、VB-Cable）——任何扩展程序都无法把自己注册成麦克风。「选项 → 音频输出」可以把声音送进这样一个设备，但安装设备并在会议里选中它仍要你自己完成。
• 两个方向都用扬声器会引来回声循环。请戴耳机。在以出声说话为前提的双向对话模式下，改为让麦克风远离扬声器。
• 词汇表只对麦克风的双向对话模式生效。其余部分使用 Google 的同声翻译模型，它不接受词汇表。
• 两个方向意味着两个并行的 Gemini 会话，因此你密钥上的 API 用量大约会翻倍。
• Chrome 不允许扩展程序在自家页面、网上应用店和 PDF 上绘制内容，那些地方不会出现字幕。音频和侧边栏记录仍然可用。

▍ 费用

Interpretab 免费且开源。Gemini API 的用量按 Google 的价格计入你自己的 Google 账号；免费额度足够你好好试一遍。请把密钥当密码看待：不要分享；万一泄露，就到 aistudio.google.com/apikey 删掉它，再把新的粘贴到「选项」页面。
