The interpreted voice is muted. Click the unmute button to play it through your speakers. Note: wear headphones when you play it. This mode answers while you are still speaking, so it cannot mute the microphone while it talks, and a speaker feeds the translation straight back in — which degrades the translation itself.

For two people sharing this microphone: whichever of the two languages it hears, it speaks the other. Out loud, through your speakers, which is the point — but it means the interpreter can hear itself, so keep the microphone away from them. This mode waits for each turn to finish, so it is a little slower than Simultaneous, and it is the only one the glossary applies to.

Both directions run two concurrent Live sessions, so the API usage is roughly double.
