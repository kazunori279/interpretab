{%- comment -%} A copy of jekyll-theme-primer's own default layout — which is what this site rendered with before the file existed — with two things added. The first is `dir`. Nine of the ten guide pages read left to right and one does not, and the direction of a document belongs on its root element, where every logical CSS property and every bidi calculation in the page can see it. The second is the language bar. It used to be a line of markdown repeated at the top of ten pages, each with a different entry in bold and every link written out nine times; a language added anywhere meant editing all of them. Here it is one loop over `_data/languages.yml`, and a page opts in by declaring `lang` in its front matter — which `PRIVACY.md` does not, so it does not get a bar it has no translations for. {%- endcomment -%} {%- comment -%} `page.lang` is the guard on everything below, and `self` is never trusted on its own. Two reasons, both quiet: `where` handed nothing to match on does not answer with nothing, and an `assign` inside an `if` survives into the next page that renders through this layout, because the parsed layout is reused and its variables live on it. So the assignment is unconditional and the test is not. {%- endcomment -%} {%- assign languages = site.data.languages -%} {%- assign self = languages | where: "code", page.lang | first -%} {% seo %} {% include head-custom.html %}
